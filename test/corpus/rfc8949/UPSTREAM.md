# RFC 8949 examples

From [RFC 8949](https://www.rfc-editor.org/rfc/rfc8949.txt), *Concise Binary Object
Representation (CBOR)*, December 2020, by C. Bormann and P. Hoffman.

| File | From |
|------|------|
| `appendix-a.txt` | Appendix A, "Examples of Encoded CBOR Data Items": each row's encoding (hex, without `0x`), a tab, and its diagnostic notation. Rows that span lines in the RFC are joined. |
| `appendix-f.txt` | Appendix F.1, "Examples of CBOR Data Items That Are Not Well-Formed": each example (hex, without spaces), a tab, and the RFC's heading for it. |

Extracted by a script from the RFC's plain text on 2026-11-22; nothing else was changed.
